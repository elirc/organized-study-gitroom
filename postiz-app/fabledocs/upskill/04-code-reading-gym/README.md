# 04 — Code Reading Gym

Reading is the skill interviews actually test in the "here's some code" round. Work these actively, pen in hand.

1. [01-annotation-drills.md](01-annotation-drills.md) — 10 real excerpts to dissect (inputs/outputs/invariants/failures).
2. [02-trace-tables.md](02-trace-tables.md) — 6 step-by-step data traces across layers.
3. [03-fake-code-contrasts.md](03-fake-code-contrasts.md) — 10 bad-vs-better pairs tied to real repo patterns (all fake code labeled).
4. [04-review-katas.md](04-review-katas.md) — 10 simulated PRs to review, with graded findings and model comments.

Do drills → traces first (comprehension), then contrasts → katas (judgment). The katas are the closest thing to a real code-review interview round.
